## 同场景新版对照

保持历史的 21 个固定场景及其预期不变，每种模式三轮，共 189 次执行。每轮 12 个存在正确目标，去除 1 个原本成功的场景，每种模式有 33 次需要恢复的失败；另有 27 次应拒绝修复。

| 模式 | 恢复 / 可恢复失败 | 应拒绝场景均拒绝 | 观察到误选 | 实际模型 HTTP 请求 |
|---|---:|---:|---:|---:|
| 关闭自愈 | 0/33 | 27/27 | 0 | 0 |
| 纯规则 | 33/33 | 27/27 | 0 | 0 |
| 混合模式 | 33/33 | 27/27 | 0 | 0 |

混合模式被启用，但候选都由规则完成，因此 `model_requested=true`、`model_evaluated=false`。不能把该表称为新版模型效果实测；真实模型能力证据来自另外的计划生成运行。小规模固定场景全通过不代表线上误修概率为零，也不代表 63 个独立场景。

这轮结论是：v0 的部分模型收益来自规则缺项。补全语义定位后，相同场景无需再付出模型调用成本。项目的 AI 部分定位于页面证据辅助生成、可选分析与有界候选建议，执行和验证仍由明确规则约束。

完整筛选结果见 [v1 实验 JSON](v1-evaluation-results.json)。此前 [历史实验](evaluation-2026-11-08.md)及原始结果保留，不能与本表数字拼接。
