# Healer 安全自愈恢复开发计划

**目标：** 保留现有 Python/Playwright 架构，阻止无目标依据的自动修复，区分操作恢复与业务验证，提供离线可复现证据。

**授权与范围：** 用户已授权全权负责，沿用当前工作区；不调用付费模型、不改求职主表、不部署。先完成可靠性闭环，不扩建平台。

**依据：** https://playwright.dev/python/docs/locators 与 https://playwright.dev/python/docs/actionability 。唯一、可见和可操作是必要条件，不能代替业务目标识别。
